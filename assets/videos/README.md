# Video replacements

Add web-ready MP4 files here:

- `training-video.mp4`
- `boxing-training.mp4`
- `personal-training.mp4`
- `gallery-video-01.mp4`, `gallery-video-02.mp4`

Use a standard HTML `<video controls poster="assets/images/...">` element in the matching placeholder location. This keeps the existing responsive layout intact.
